# dsh-web-plugin-manager 0.6.3 更新通知

**市场页排序与双列对齐修复 + 标签机制跟随上游 + 一轮跨模块深度优化**

## 修复

- **修复市场页排序方向错误**：星数/更新时间/发布时间此前实际是「升序」而按钮显示「降序」，且星数排序把 0 星条目排到最前（1.3 万条里最多有 841 条越位到首屏）。现在四个排序模式共用一个方向状态，按钮文案与实际方向同源，已安装条目恒定置顶（优先级而非排序键，反向也不掉队）。
- **修复双列显示不齐**：卡片改为等高槽位（标题 / 标签两行 / 描述两行 / 日期），同行两卡实测高度差 0px；标签超出行宽用省略而不是换行；描述统一两行截断；滚动占位高度与实际一致，滚动条不再跳动。
- **修复「更新」按钮与「中风险」标签颜色失效**：`--dsw-alias-state-warning-primary` 这个 token 官方并不存在（真名 `state-warn-primary`），导致警示色静默回退、按钮背景透明。同类问题还有环境变量表单的背景与边框（`fill-base` / `border` 两个不存在的 token）。
- **修复质量门漏检子路径入口**：一个包只要根入口干净就能通过质量门，其 `./server`、`./plugin` 等子路径入口里的未声明依赖全被漏过——这类包会在挂载时让**整个 profile 起不来**。现在扫描全部顶层导出键，并修复了 scoped 子路径解析的假阳性。
- **修复挂载行重复 id 导致 profile 无法启动**：读取挂载行时会把嵌套的 `config.name` 当成模块名、或在缺 name 时继承下一行的 name，使 id 冲突守卫失效、写出重复 id（loader 抛 `duplicate loader entry id`）。
- **修复未闭合标记静默丢弃用户配置**：补丁文件里一个未闭合的管理标记会让后续写入丢弃其后的全部用户内容；现在保留用户内容，只回收孤儿标记。
- **修复市场列表可能返回过期数据**：列表管道的缓存键不含条目身份，离线兜底时会把上一次的全量结果当成新结果返回（条目、来源、计数全部张冠李戴）。

## 新增与优化

- **分类筛选**：上游 CI 分类器给每条仓库一个功能分类（工具/记忆/界面/编码/Agent/对话/通知/模型/视觉/文档/资源），市场页新增分类下拉（带条数），服务端聚合计数、客户端兜底，两处同一实现。未知分类原样显示，不做归一。
- **标签机制跟随上游**：卡片标签统一由共享纯函数产出，顺序固定为「分类 → 类型 → 审核状态 → dsh.so 认证 → 安全等级 → 话题」，跨类型同名去重；标签改用官方 `Tag` 组件（胶囊形 + 语义色），与官方插件页视觉一致。
- **市场刷新与响应显著提速**：列表包络的字节数与 gzip 结果改为缓存（此前每个请求都重新计算 6.9MB 的字节长度并重新压缩，实测暖路径 120ms → 0.9ms）；gzip 级别调整为 3（压缩耗时 110ms → 49ms，体积 +8.6%）；进程表扫描在 Linux 上直读 `/proc`（14.5ms → 2.5ms）；索引磁盘缓存改为紧凑 JSON（1.93MB → 1.48MB）；市场列表的已安装标记与分类聚合不再每请求重算。
- **市场页交互提速**：模糊搜索加入字符掩码预筛（1.3 万条 × 2 字段实测 25.1ms → 8.9ms 每键击，命中结果与分数逐条一致）；排序的字符串比较改用共享 `Intl.Collator`（-33%~36%，顺序逐条不变）；滚动加载改为分批渲染（滚到底父层开销 539.9ms → 7.7ms）。
- **搜索框补上焦点态**（此前键盘用户看不到焦点），卡片改用官方 elevation 描边与 14px 圆角。
- **依赖面修正**：`@deepseek-ai/dsh-tools` 的 peer 范围此前写作 `^0.1.0-rc.6`（语义上等于「兼容 0.1.0 系列」，无法表达我们真正验证过的版本），已对齐到官方发布的 0.1.5-rc.2；移除未使用的 `dsh-invariants` 开发依赖。
- **官方跟进结论**：官方最新 tag 仍是 `dsh-v0.1.5-rc.2`，其后的 139 个提交无破坏性变更（平台种子表与 slot 契约逐字相同）。

## 内部质量

新增 145 项自动化测试（157 → 302），覆盖：市场标签契约、排序方向与稳定全序、分类聚合与筛选、双列等高的结构断言（含无头浏览器实测）、管道缓存键正确性、质量门入口收集、挂载行解析、补丁文件往返幂等、性能改动的逐条等价性。另有 5 套独立验证脚本（排序/标签/布局/分类筛选/缓存键/补丁往返）作为发布前门禁。

- **升级方式**：在「管理」页签对 dsh-web-plugin-manager 执行更新，或运行 `dshpm update dsh-web-plugin-manager`。
