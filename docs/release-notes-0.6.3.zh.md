# dsh-web-plugin-manager 0.6.3 更新通知

**市场页体验修复 + 一批会导致环境起不来的问题修复**

- **修复市场页排序**:此前星数、更新时间、发布时间三个排序的实际方向与按钮显示相反,星数排序还会把没有星标的插件排到最前面;现在排序方向与按钮一致,已安装的插件恒定置顶。
- **修复双列显示不齐**:市场页卡片改为等高布局,同一行两张卡片高度完全一致,标签多少、描述长短都不再让卡片参差;滚动时列表高度也不再跳动。
- **修复警示色失效**:市场页「更新」按钮与中风险提示此前颜色不生效,看起来和普通文字没有区别;现已恢复为醒目的警示色,安装时的环境变量填写框也恢复边框与底色。
- **新增分类筛选**:市场页可按插件功能分类筛选(工具、记忆、界面、编码、Agent 等),下拉中带每类数量;分类取自上游索引,上游新增分类会自动出现,无需等待插件更新。
- **标签显示更清晰**:卡片标签统一为「分类、类型、审核状态、认证等级、安全等级、话题」的顺序,同类标签不再重复,样式与官方插件页一致。
- **修复一批会导致环境起不来的问题**:安装检查此前漏掉了插件子入口中的缺失依赖,这类插件装上后可能让整个环境启动失败;另修复了插件挂载记录重复、配置文件中未闭合标记会静默丢掉用户后续内容、网络不稳时市场可能显示上一次的旧列表、安装守卫可被特定命令写法绕过等问题。
- **修复若干功能失效**:「技能与预设」页的卸载与重新安装此前必定失败;检查更新会把个别降级当成新版本提示,还可能长时间卡住请求;健康检查给出的建议加载顺序前后颠倒;备份文件超过 1MB 时无法恢复;安装时填写的环境变量在仓库已发布到 npm 的情况下会被丢弃。
- **市场页明显更快**:重复打开市场、切换环境、搜索、长列表滚动都快了很多,搜索每敲一个键的等待感基本消失,插件数量过万时滚动到深处也不再卡顿。
- **兼容最新官方版本**:适配 DeepSeek Harness 0.1.5-rc.2,已在真实环境完整验证;旧版 DSH 不受影响,无需陪同升级。
- **升级方式**:在「管理」页签对 dsh-web-plugin-manager 执行更新,或运行 `dshpm update dsh-web-plugin-manager`。

反馈与建议欢迎提交 issue:https://github.com/LX2000WASD/dsh-web-plugin-manager
