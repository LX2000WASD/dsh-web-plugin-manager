# dsh-web-plugin-manager 0.6.3 更新通知

> 本版**合并了 0.6.2 的全部内容**（0.6.2 未发布到 npm）。从 0.6.1 升级会一次拿到下面所有修复与优化。

**市场页排序与双列对齐修复 + 标签机制跟随上游 + 兼容官方 0.1.5-rc.2 + 一轮跨模块深度优化**

## 市场页（用户实测反馈）

- **修复排序方向错误**：星数/更新时间/发布时间此前实际是「升序」而按钮显示「降序」，且星数排序把 0 星条目排到最前（1.3 万条里最多有 841 条越位到首屏）。现在四个排序模式共用一个方向状态，按钮文案与实际方向同源，已安装条目恒定置顶（优先级而非排序键，反向也不掉队）。
- **修复双列显示不齐**：卡片改为等高槽位（标题 / 标签两行 / 描述两行 / 日期），同行两卡实测高度差 0px；标签超出行宽用省略而不是换行；描述统一两行截断；滚动占位高度与实际一致，滚动条不再跳动。
- **修复「更新」按钮与「中风险」标签颜色失效**：`--dsw-alias-state-warning-primary` 这个 token 官方并不存在（真名 `state-warn-primary`），导致警示色静默回退、按钮背景透明。同类问题还有环境变量表单的背景与边框（`fill-base` / `border` 两个不存在的 token）。
- **新增分类筛选**：上游 CI 分类器给每条仓库一个功能分类（工具/记忆/界面/编码/Agent/对话/通知/模型/视觉/文档/资源），市场页新增分类下拉（带条数），服务端聚合计数、客户端兜底，两处同一实现。未知分类原样显示，不做归一。
- **标签机制跟随上游**：卡片标签统一由共享纯函数产出，顺序固定为「分类 → 类型 → 审核状态 → dsh.so 认证 → 安全等级 → 话题」，跨类型同名去重；标签改用官方 `Tag` 组件（胶囊形 + 语义色），与官方插件页视觉一致。
- **搜索框补上焦点态**（此前键盘用户看不到焦点），卡片改用官方 elevation 描边与 14px 圆角。

## 兼容官方 DSH 0.1.5-rc.2

- 适配官方最新发布版 0.1.5-rc.2，已在真实环境完整验证；旧版 DSH 不受影响，无需陪同升级。
- 官方最新 tag 之后还有 139 个提交，已逐面核对：**零破坏性变更**（客户端平台模块表与设置页 slot 契约逐字相同）。

## 修复（0.6.2 批次，本次一并发布）

- **修复「技能与预设」页的卸载/重新安装失效**：此前这两个按钮必定失败（服务端把空环境名当成非法参数直接拒绝），现在可以正常使用。
- **修复更新检测的版本号判断**：预发布版本之间的先后比较有误，个别情况下会把「降级」当成可用更新提示出来。
- **修复检查更新可能卡住请求**：该操作改为后台任务 + 进度轮询，不再让浏览器长时间等待（实测从数秒阻塞降到 17ms 返回）。
- **修复「建议加载顺序」颠倒**：健康检查里给出的加载顺序此前把依赖方排在被依赖方前面，现在按正确顺序展示。
- **修复环境变量在 npm 安装路径下被丢弃**：仓库已发布到 npm 时，用户刚填写的安装期变量不再被忽略。
- **修复官方重复包清理不彻底**：清理后同步更新依赖锁，避免下次安装又把刚删掉的拷贝装回来。
- **修复备份恢复的大小限制**：备份文件超过 1MB 时不再报「请求体过大」，插件较多的环境也能正常恢复。
- **更安全的环境变量输入**：凭据类变量默认以密文显示，可点击「显示」查看。
- **安装守卫减少误报**：npm 脚本形式的安装调用不再被误判为危险的依赖变更。
- **其他修复**：健康检查里修复按钮的状态不再串行错位；插件市场切换环境时会真正取消上一次加载；页面在环境变量表单打开时不再允许并发安装。

## 修复（本轮新增，均为会导致启动失败或数据损坏的问题）

- **修复质量门漏检子路径入口**：一个包只要根入口干净就能通过质量门，其 `./server`、`./plugin` 等子路径入口里的未声明依赖全被漏过——这类包会在挂载时让**整个 profile 起不来**。现在扫描全部顶层导出键，并修复了 scoped 子路径解析的假阳性。
- **修复挂载行重复 id 导致 profile 无法启动**：读取挂载行时会把嵌套的 `config.name` 当成模块名、或在缺 name 时继承下一行的 name，使 id 冲突守卫失效、写出重复 id（loader 抛 `duplicate loader entry id`）。
- **修复未闭合标记静默丢弃用户配置**：补丁文件里一个未闭合的管理标记会让后续写入丢弃其后的全部用户内容；现在保留用户内容，只回收孤儿标记。另修复了「无操作也重写补丁文件、顶掉用户自写注释头」的问题。
- **修复市场列表可能返回过期数据**：列表管道的缓存键不含条目身份，离线兜底时会把上一次的全量结果当成新结果返回（条目、来源、计数全部张冠李戴）。
- **修复安装守卫可被绕过**：把 profile 参数写在子命令之前的官方 CLI 写法此前不触发守卫，AI 安装可绕过质量门。

## 性能优化

- **市场刷新与响应**：列表包络的字节数与 gzip 结果改为缓存（此前每个请求都重新计算 6.9MB 的字节长度并重新压缩，实测暖路径 120ms → 0.9ms）；gzip 级别调整为 3（压缩耗时 110ms → 49ms，体积 +8.6%）；进程表扫描在 Linux 上直读 `/proc`（14.5ms → 2.5ms）；索引磁盘缓存改为紧凑 JSON（1.93MB → 1.48MB）；市场列表的已安装标记与分类聚合不再每请求重算。
- **市场页交互**：模糊搜索加入字符掩码预筛（1.3 万条 × 2 字段实测 25.1ms → 8.9ms 每键击，命中结果与分数逐条一致）；排序的字符串比较改用共享 `Intl.Collator`（-33%~36%，顺序逐条不变）；滚动加载改为分批渲染（滚到底父层开销 539.9ms → 7.7ms）。
- **长任务感知**：后台任务轮询改为短间隔起步，短任务平均感知延迟 1499ms → 874ms（最坏情况不劣化）。
